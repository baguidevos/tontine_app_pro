1. Introduction

Bienvenue sur Paya ("l'Application"). Nous respectons votre vie privée et nous nous engageons à protéger vos données personnelles. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre application mobile.

⚠️ Important : En utilisant Paya, vous acceptez les pratiques décrites dans cette politique.

2. Données collectées

Nous collectons les types de données suivants :

2.1 Données que vous nous fournissez

  • Informations de compte : Nom, adresse email, mot de passe (crypté)
  • Informations professionnelles : Nom de votre entreprise, type de commerce
  • Données de tontine : Vagues créées, produits, commandes, clients
  • Informations clients : Noms et détails de vos clients (que vous ajoutez dans l'app)

2.2 Données collectées automatiquement

  • Identifiants d'appareil : ID unique de votre appareil
  • Données d'utilisation : Fonctionnalités utilisées, fréquence d'utilisation
  • Logs d'application : Informations sur les performances et les erreurs
  • État de connexion : Statut en ligne/hors-ligne

2.3 Données NON collectées

✅ Nous ne collectons PAS :
  • Vos données de localisation GPS
  • Vos contacts téléphoniques
  • Vos photos personnelles (seules les photos de produits sont stockées)
  • Vos informations bancaires ou de paiement

3. Utilisation des données

Nous utilisons vos données pour :

  1. Fournir le service : Gérer votre compte, vos vagues de produits et vos commandes
  2. Améliorer l'application : Analyser l'utilisation pour améliorer les fonctionnalités
  3. Sécurité : Authentifier votre compte et protéger contre les accès non autorisés
  4. Support : Répondre à vos demandes d'assistance
  5. Notifications : Vous informer des mises à jour importantes (optionnel)

4. Firebase et services tiers

Paya utilise Google Firebase comme backend. Cela signifie que vos données sont stockées sur les serveurs sécurisés de Google Firebase.

4.1 Données stockées sur Firebase

  • Informations de compte (authentification Firebase)
  • Données de tontine (vagues, produits, commandes, clients)
  • Préférences utilisateur

4.2 Politique de Firebase

L'utilisation de Firebase est soumise à la Politique de Confidentialité de Google. Vos données sont protégées par les mesures de sécurité de Google Cloud.

5. Partage des données

🔒 Nous NE vendons PAS vos données personnelles.

Nous partageons uniquement vos données dans les cas suivants :

  • Avec Firebase/Google : Pour le stockage et l'authentification (nécessaire au fonctionnement)
  • Avec votre consentement : Si vous choisissez de partager des données
  • Obligation légale : Si requis par la loi ou une autorité judiciaire

6. Sécurité

Nous mettons en œuvre des mesures de sécurité pour protéger vos données :

  • 🔐 Authentification sécurisée : Mots de passe cryptés via Firebase Auth
  • 🔒 Données cryptées : Transmission via HTTPS/TLS
  • 🛡️ Protection Firebase : Règles de sécurité Firestore
  • 📱 Isolation des données : Chaque vendeur ne voit que ses propres données
⚠️ Limitation : Aucune méthode de transmission sur Internet n'est 100% sécurisée. Nous faisons de notre mieux pour protéger vos données, mais nous ne pouvons garantir une sécurité absolue.

7. Vos droits

Vous avez les droits suivants sur vos données :

  • ✅ Accès : Demander une copie de vos données
  • ✅ Rectification : Corriger des données inexactes
  • ✅ Suppression : Demander la suppression de votre compte et de vos données
  • ✅ Export : Exporter vos données (fonctionnalité dans l'app)
  • ✅ Opposition : Vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à davidhida108@gmail.com

8. Cookies

Paya n'utilise pas de cookies traditionnels. Cependant, l'application peut utiliser :

  • Stockage local : Pour sauvegarder vos préférences et permettre le mode hors-ligne
  • Identifiants Firebase : Pour maintenir votre session connectée

9. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. Nous vous notifierons de tout changement important via l'application ou par email. La version la plus récente sera toujours disponible dans l'application et sur cette page.
